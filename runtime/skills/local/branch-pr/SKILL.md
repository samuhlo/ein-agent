# Branch and PR compatibility alias

`github-workflow` owns branch and PR delivery. Load
`../github-workflow/SKILL.md` for current instructions.

A GitHub issue is optional. Link one when the user requests it or the repository
actually requires it; never create an issue merely to open a PR. Linear, when
enabled, has its own board. The PR's `[[TAG]]` title badge and `// NNN` body
follow the `ein-git` delivery contract and any actual repository template.
